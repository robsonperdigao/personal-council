# Adding advisors and seats

A **seat** defines a job (e.g., family, strategy, inner life). An **advisor** defines a chosen perspective and may occupy that seat. Seats and advisors have stable IDs. A **guest** attends one meeting without changing assignments.

## Guided flow
Ask: "Use add-advisor to put [name] in my [seat] chair." The agent should check existing seats, propose a draft, show sources and limits, then request approval before writing and assigning.

## Manual flow
1. Copy advisors/templates/advisor-template.md.
2. Choose a unique lowercase hyphenated ID.
3. Set type = historical | fictional | personal | original.
4. Describe the mandate, reasoning style, limitations and source notes.
5. Place public, evidence-based general profiles in advisors/; place personal profiles only in the private workspace advisors/.
6. Edit the row in your private council.md to assign the new advisor ID. Confirm the change.
7. Do not rewrite previously saved decisions; they record earlier participants.

## Sources and care
Historical views require source notes; if not verified, say so. Fictional perspectives must not falsely claim to reproduce canon. Personal profiles should prioritize teachings and the user's own recollections; mark interpretations as tentative. Conversations inspired by a deceased loved one must never imply the person is present or communicating.

## Review checklist
- Unique ID and valid type.
- No fabricated citations or personal facts.
- Clear mandate and boundaries.
- No sensitive information in public files.
- User approved changing the seat.

## Personality design workflow (M2)

Use advisor-architect before installing a new public profile. The [advisor personality guide](ADVISOR_DESIGN.md) defines the required sections: source-backed principles, a distinct decision method, communication, dissent, signature questions, illustrative examples and limits.

Before changing a seat, show the proposed Markdown profile and mapping, request approval, and preserve previous advisor IDs in decision records. Compare different advisors against a shared fictional dilemma rather than assuming a famous name guarantees a new perspective.

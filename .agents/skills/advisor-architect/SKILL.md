# Advisor Architect

Read constitution.md, docs/ADVISOR_DESIGN.md and advisors/templates/advisor-template.md. Build an intellectual lens, not a costume.

1. Identify the requested advisor, type (historical, fictional, personal, original) and intended mandate; distinguish the seat from its occupant.
2. Research primary or trustworthy secondary sources for historical/fictive claims. Mark uncertainty when sources cannot be verified; do not fabricate quotes.
3. Extract three to five distinctive principles and acknowledge conflicts and limitations.
4. Define an ordered reasoning process (four to six steps) that changes which evidence is considered.
5. Specify temperament, communication pace, questions, dissent and caricatures to avoid.
6. Write an original, illustrative response to the SAME fictional dilemma used for other advisors. Do not present it as a genuine quotation.
7. Compare perspectives without their name labels: if their diagnoses are interchangeable, refine the method.
8. Propose a complete Markdown profile and source notes for review before writing it.
9. Store personal advisors only in an approved PRIVATE workspace. Never transfer a relative's memories into the public repository.
10. Hand off approved profiles to add-advisor for seat assignment; preserve past decision history.

Default to one Markdown file. Optional extra reference files are allowed, but no database, fine-tuning or subagent runtime is required.

# Memory Manager

1. Read docs/MEMORY_FORMAT.md and constitution.md.
2. Locate an explicitly configured private workspace. Never assume cross-chat or cloud access.
3. For retrieval, read memory/index.md first and fetch only pertinent domain files and decision records. State when files are missing.
4. For writes, draft the smallest necessary change and show what file will change. Get explicit user approval before persisting.
5. Label provenance: user-stated, documented-source, inference, hypothetical. Never silently promote inference to fact.
6. Use portable relative Markdown links to relate topics, decisions and sources. Do not use proprietary syntax as the only reference.
7. Maintain stable decision IDs; prefer append-only outcome reviews and dated corrections.
8. If memories disagree, show the conflict and ask how to resolve it; do not silently prefer the newest.
9. For cross-domain access, ensure relevance and permission, and avoid copying sensitive context unnecessarily.
10. If no file write tool exists, present a copyable Markdown patch and plainly state that it was not saved.

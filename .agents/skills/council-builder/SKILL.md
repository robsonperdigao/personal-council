# Council Builder

1. Read constitution.md and ARCHITECTURE.md.
2. Determine whether a private workspace already exists; never overwrite without consent.
3. Ask only for missing essentials: desired domains/seats, preference for advisor types, preferred language and workspace location. Accept partial answers and reasonable defaults.
4. Offer initial seats without forcing a fixed number. A seat is a function; an advisor is replaceable.
5. Offer matching advisor IDs from advisors/historical/ and private profiles if accessible. Do not invent availability of uncreated profiles.
6. Propose the files to create from templates/private/: council.md, profile.md, memory/index.md and memory/values.md.
7. Before writing any personal data, get explicit approval. Never create public files containing private biography.
8. Describe how to invoke council-session and add-advisor next.

If no writable filesystem is available, show a copyable Markdown configuration and state that persistence was not performed. Obsidian and Notion are not required.
